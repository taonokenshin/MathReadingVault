# Public English study archive

[Download the complete study ZIP](MathReadingVault_English_Study_Archive_2026-10-20_Public.zip), then extract it and open `START_HERE.md`. GitHub may show a download button for the ZIP.

The 20 October 2026 snapshot contains 1,152 English mathematical articles and 1,124 normalized educational session records, with textbook-order guides, reader prefaces, stable source handles and honest proof-status labels. See the [archive guide](../docs/ARCHIVE.md) for scope and unresolved boundaries.

The ZIP is 8,540,794 bytes. SHA-256: `ea2635fcdc338c9938dee91cd2bf545aa46bf5307c89e3a902b6af398ed37d67`. The [checksum file](SHA256SUMS.txt) and [editorial validation report](archive_validation.json) accompany it. Validation checks privacy patterns, file links, syntax and transport; it does not certify proofs or distribution rights.

Source PDFs, page images, the raw private archive, account information, automation memory and operational state are excluded. Original prose licensing and third-party exclusions follow the repository licenses and notices.

The archive is stored here so that it is available through the ordinary repository download channel. The [dated release](https://github.com/taonokenshin/MathReadingVault/releases/tag/study-edition-2026-10-20) documents the same export.
