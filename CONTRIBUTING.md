# Contributing

Small, traceable contributions are welcome: reproduce a controller bug in a temporary fixture; improve portable configuration; repair a broken source reference; explain a mathematical dependency; or submit a narrowly stated correction with hypotheses and evidence.

For software, include the exact command, Python version, expected behavior, actual result, and a minimal synthetic example. Run the isolated tests. Never run experiments against another contributor's actual automation directory. Avoid dependencies unless the change needs them.

For mathematics, identify book, chapter/section, stable article ID and the precise claim. Distinguish a typographical repair, a reader-note error, a missing hypothesis, a cited input and a suspected source issue. Explain what dependent conclusions change. Do not promote a proof label merely because an explanation is polished or a finite example passes. Existing historical errors may remain as explicitly superseded learning records.

Do not submit copyrighted textbook PDFs/scans, long copied source passages, private learner information, credentials, account/quota state, automation memory, live locks or full chat transcripts. Cite lawfully available source locations and keep external quotations attributed. Discuss uncertain distribution rights before adding material.

Open an issue for a focused problem and a pull request for a reviewable change. The maintainer may use Codex in triage/review; AI assistance does not remove the contributor's responsibility to make scope and sources clear. Original code contributions follow the MIT license; original prose contributions follow LICENSE-CONTENT.md, excluding third-party material.
